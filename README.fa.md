# دستخط

دستیار خواندن و نوشتن فارسی برای کروم، اج و فایرفاکس. راست‌چین و فونت فارسی در هر سایت، هایلایت متن و بازنویسی و ترجمه با هوش مصنوعی و کلید API خودتان.

## امکانات

- **حالت فارسی:** راست‌چین‌کردن خودکار و اعمال فونت فارسی روی صفحه‌ها و فیلدهای متنی. برای هر صفحه یا برای دامنه‌های دلخواه (مثل ChatGPT، Claude و Gemini) خودکار فعال می‌شود.
- **هایلایت:** متن را انتخاب و هایلایت کنید؛ با بازگشت به صفحه سر جایش است.
- **دستیار هوش مصنوعی:** بهبود، ترجمه، خلاصه و اصلاح دستور متن انتخاب‌شده، با ارائه‌دهنده‌ای که خودتان انتخاب می‌کنید.
- **حریم خصوصی:** بدون حساب کاربری، ردیابی و کد راه‌دور. جزئیات در [PRIVACY.md](PRIVACY.md).

## نصب و توسعه

```bash
npm run build
```

سپس پوشه‌ی `dist/chrome` را در کروم یا اج با «Load unpacked» بارگذاری کنید. راهنمای کامل مشارکت در [CONTRIBUTING.md](CONTRIBUTING.md) است و مجوز پروژه [MIT](LICENSE) است.
